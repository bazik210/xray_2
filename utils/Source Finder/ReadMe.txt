Info:
Browses target directory and saves all found source file paths into a text file.
Use only if there are no projects associated with the files and you have to find all files manually.

How to use:
1. Edit the script and adjust the root path, as well as regex at the bottom of the script.
2. Run SourceFinder.py using cmd (Python required)

Outputs info:
1. Found source file names are outputted into 'found' directory as filepaths that are ready to be pasted into CMakeLists.
